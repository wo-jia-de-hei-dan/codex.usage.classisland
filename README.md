# Codex 使用量组件

适用于 ClassIsland 2.1.0.1 的插件，在主界面组件中显示 Codex 每周使用量和可用的免费重置额度。

## 功能

- 自动读取本机 Codex 登录状态。
- 显示剩余百分比、重置时间、更新时间和连接状态。
- 如果 Codex 返回免费重置额度，会单独显示免费额度的剩余百分比和重置时间；未返回时显示“暂未提供”。
- 免费重置额度仅用于显示，不参与低额度提醒或自动化规则。
- 设置页支持 auth 文件路径、刷新间隔、低额度阈值和低额度提醒。
- 提供 ClassIsland 自动化规则：`Codex 剩余额度低于`。
- 额度从阈值以上跨到阈值以下时可触发 ClassIsland 提醒。

## 使用

1. 在 ClassIsland 设置 → 插件 → 从本地安装中选择 `.cipx` 文件。
2. 重启 ClassIsland。
3. 在组件编辑器中添加“Codex 使用量”。
4. 在插件设置页确认 auth 文件路径和阈值。
5. 在自动化规则集中选择“Codex 剩余额度低于”，再配置“显示提醒”等行动。

插件只读取本机 Codex 登录状态，不保存 ChatGPT 密码、登录令牌或 cookies，也不会把认证内容写入日志。
