# 免费重置额度显示设计

## 目标

在现有 ClassIsland Codex 使用量插件中增加“免费重置额度”的独立显示，同时保持现有每周额度的提醒和自动化行为不变。

## 范围

- 解析 Codex 使用量响应中的免费重置额度信息。
- 在共享使用量快照中增加可选的免费额度数据。
- 在组件中增加独立的“免费重置额度”卡片，显示剩余百分比和重置时间。
- 当接口未返回该额度、字段缺失或格式无法识别时显示“暂未提供”，不把缺失值当作 0%。
- 保持现有设置、提醒提供方和自动化触发器不变；本次不增加免费额度阈值设置、提醒或规则。

## 方案

沿用现有响应解析器、`UsageSnapshot` 和组件刷新链路。免费额度作为独立字段建模，避免与每周额度合并。解析器优先读取明确的免费重置额度节点，并兼容字段缺失；组件只消费快照，不直接解析 JSON。

## 数据流

Codex 响应 → `UsageResponseParser` → `UsageSnapshot`（每周额度 + 可选免费额度） → `UsageService` → `CodexUsageComponent`。

免费额度仅用于展示，不参与 `UsageNotificationService`、`CodexUsageLowTrigger` 或现有阈值状态机。

## 错误处理

- 缺少免费额度节点：保留每周额度并将免费额度标记为不可用。
- 免费额度字段格式异常：忽略该字段，组件显示“暂未提供”。
- 整体响应异常：沿用现有错误状态和上次成功快照策略。
- 不记录完整响应、Token、API Key 或本机认证内容。

## 测试

- 免费额度字段存在时，解析剩余比例和重置时间。
- 免费额度字段缺失时，解析仍成功且免费额度不可用。
- 免费额度字段格式异常时，不影响每周额度解析。
- 组件数据绑定显示独立的免费额度卡片。
- 现有解析、设置持久化、提醒和自动化测试继续通过。
